# TechNova-Enterprise-Network-Infrastructure
Diseño e implementación de una infraestructura de red empresarial segura y segmentada mediante VLANs, routing, servicios de red, administración de servidores y políticas de control de acceso. Proyecto desarrollado con Cisco Packet Tracer, enfocado en infraestructura IT, redes empresariales y ciberseguridad.
