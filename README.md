## Descripción del proyecto

Este proyecto consiste en el diseño e implementación de una infraestructura de red empresarial para **TechNova Solutions**, una empresa ficticia que requiere una infraestructura tecnológica segura, escalable y organizada.

La solución contempla la segmentación de la red mediante VLANs, configuración de routing, administración de servicios de infraestructura, control de acceso y aplicación de políticas de seguridad.

El proyecto se desarrolla utilizando Cisco Packet Tracer y herramientas complementarias de administración y análisis de redes.
